# Open Papertrade

### About

<mark style="color:$primary;">**Open-Papertrade**</mark> is a learning platform for retail trading that sits at the intersection of finance and applied AI. It goes beyond simulated trades: users can run virtual portfolios on <mark style="background-color:blue;">**live market data**</mark>, backtest strategies over historical windows, follow other traders, receive <mark style="background-color:blue;">**behavioral coaching from an LLM**</mark> based on their own trade history, and interrogate <mark style="background-color:blue;">**SEC filings**</mark> through an <mark style="background-color:blue;">**agentic RAG pipeline**</mark> that cites every claim and declines when the corpus doesn't support an answer.

The project is designed both as a functioning product and as a reference implementation of several real-world AI patterns — provider-agnostic LLM abstractions, hybrid dense/sparse retrieval with cross-encoder reranking, static agent decomposition over tool-use loops, and honest refusal behavior grounded in the eval numbers.
